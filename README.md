# Data Structures Used

# List
A List stores multiple values in order. It is mutable, allows duplicate values, and its items can be accessed using indexes.

# Tuple
A Tuple stores multiple values in order. It is immutable, allows duplicate values, and its items can be accessed using indexes.

# Set
A Set stores unique values. Duplicate values are automatically removed, and items do not have a fixed indexed position.

# Dictionary
A Dictionary stores information as key-value pairs. It is mutable, keys must be unique, and values can be accessed using their keys.
